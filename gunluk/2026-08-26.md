# Öğrenilenler
- fetch, HTTP hata kodlarını (404, 403 gibi) kendiliğinden hata saymıyor, response.ok kontrolünü kendim yazmam gerekiyor.
- Bir Promise beklenmeden (await/return olmadan) kullanılırsa elime gerçek veri değil, bekleyen (pending) haldeki Promise'in kendisi geçiyor.
- Promise zincirinde throw edilen hata, zincirin geri kalan .then'lerini atlayıp direkt sondaki catch'e düşüyor.
- Promise ile C#'taki Task aynı mantığı taşıyor ama Task gerçek thread/paralel çalışmaya bağlıyken Promise JS'in tek thread'li event loop'una bağlı.
