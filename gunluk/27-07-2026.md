### Git ile Çalışma
- Tüm taşıma işlemleri `git mv` ile yapıldı
- Karşılaşılan hatalar ve çözümleri:
  - Büyük/küçük harf değişikliğinin git tarafından algılanmaması → geçici isimlendirme ile çözüldü
- Değişiklikler commit'lenip GitHub'a push edildi

## Öğrenilenler
- `git mv` ile normal `mv`/dosya taşıma arasındaki fark (geçmiş takibi)
- Windows'ta dosya sisteminin case-insensitive olmasının git ile yarattığı uyumsuzluk ve çözümü
- `git status`, `git ls-files`, `git log --oneline` komutlarıyla repo durumunu adım adım doğrulama
