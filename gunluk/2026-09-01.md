# Yeni Proje

- Yeni Gönderi Okuyucu projesi için "https://jsonplaceholder.typicode.com/posts?_limit=20" adresini tarayıcının arama çubuğuna yapıştırdım. Döndürdüğü şey JSON verisi; {
    "userId": 1,
    "id": 1,
    "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
    "body": "quia et suscipit\nsuscipit recusandae consequuntur expedita et cum\nreprehenderit molestiae ut ut quas totam\nnostrum rerum est autem sunt rem eveniet architecto"
  },

  
    Yani içerisinde userId, id, title ve body objelerini içeriyor. 
- userId → bu postu oluşturan kullanıcının id'si
- id → postun kendi id'si
- title → post başlığı 
- body → post içeriği 
    
    "https://jsonplaceholder.typicode.com/users" adresini de tarayıcıda açtım, karşıma çıkan;
      {
    "id": 1,
    "name": "Leanne Graham",
    "username": "Bret",
    "email": "Sincere@april.biz",
    "address": {
      "street": "Kulas Light",
      "suite": "Apt. 556",
      "city": "Gwenborough",
      "zipcode": "92998-3874",
      "geo": {
        "lat": "-37.3159",
        "lng": "81.1496"
      }
    },
    "phone": "1-770-736-8031 x56442",
    "website": "hildegard.org",
    "company": {
      "name": "Romaguera-Crona",
      "catchPhrase": "Multi-layered client-server neural-net",
      "bs": "harness real-time e-markets"
    }
  },

    Bir önceki posts verisi gönderileri temsil ederken, bu ise kullanıcıları temsil ediyor. Her obje bir kullanıcı ve şu alanları içeriyor:

- id → kullanıcı id'si
- name → kullanıcının tam adı
- username → kullanıcı adı (nickname)
- email → e-posta
- address → adres bilgisi, nested (obje içinde obje) obje: street, suite, city, zipcode
- geo → koordinatlar
- phone → telefon
- website → web sitesi
- company → şirket bilgisi, nested (obje içinde obje) obje: name, catchPhrase, bs

    Son adres olan "https://jsonplaceholder.typicode.com/posts/3/comments" adresini de tarayıcıda açtığımda: 
     {
    "postId": 3,
    "id": 11,
    "name": "fugit labore quia mollitia quas deserunt nostrum sunt",
    "email": "Veronica_Goodwin@timmothy.net",
    "body": "ut dolorum nostrum id quia aut est\nfuga est inventore vel eligendi explicabo quis consectetur\naut occaecati repellat id natus quo est\nut blanditiis quia ut vel ut maiores ea"
  },

  diğerleri gibi ama endponiti comments. 
- postId → yorumun ait olduğu postun id'si
- id → yorumun kendi id'si
- name → yorum başlığı, yorum ismi
- email → yorumu yapan kişinin e-postası
- body → yorumun asıl içeriği

    Projenin asenkron veri çekme süreçleri üzerinde çalıştım. `app.js` dosyası kapsamında gerçekleştirdiğim geliştirmeler şunlardır:

    1) DOM Entegrasyonu: HTML üzerinde yer alan `post-list` ve `search-input` elementlerini seçtim ve JavaScript tarafına bağladım.
    2) Veri Çekme:`loadPosts` adında asenkron bir fonksiyon oluşturdum. Bu fonksiyon içerisinde `fetch` kullanarak sırayla gönderiler (posts) ve sonra kullanıcıları (users) çektim. Daha sonra `loadPostsPromise` adından bir fonksiyon daha oluşturdum ve burada promise.all ile aynı anda çektim.
    3) Performans Takibi ve Karşılaştırma: Yapılan API isteklerinin ne kadar sürede tamamlandığını ölçmek amacıyla tarayıcı konsolunda fetch için `console.time("fetch")` ve `console.timeEnd("fetch")` metodları, promise için `console.time("promise")` ve `console.timeEnd("promise")` kullanarak performans analizi yaptım.
    4) Render Süreci: Çekilen gönderi ve kullanıcı verilerini ekrana basabilmek için `render(posts, users)` fonksiyonuna argüman olarak geçtim.
