# 23.08.2026 Günlük Rapor

- `yukle()` fonksiyonunu `async` yaptım, artık dizi değil Promise döndürüyor
- bunun `let gorevler = yukle()` satırını neden bozduğunu gördüm, Promise'in `.map`/`.filter` gibi array metodları yok, önce resolve olmasını beklemek gerekiyor
- `await` kullanınca hem localStorage hem fetch branch'ini aynı fonksiyon altında toplayabildim
- `https://jsonplaceholder.typicode.com/todos?_limit=5` adresine fetch attım, `await yanit.json()` ile response'u okudum, gelen alanları kendi isimlendirmeme çevirdim: `title` -> `metin`, `completed` -> `bitti`
- ağa yalnızca localStorage'da kayıt yokken gidiyor, kayıt varsa hâlâ oradan okuyor

- `let gorevler = yukle()` satırını kaldırdım, `gorevler`'i boş dizi olarak başlattım
- event listener'ları (addBtn, liste click, deleteAllBtn) veriyi beklemeden hemen bağladım, çünkü onlar `gorevler`'e closure üzerinden erişiyor, veri gelince de sorunsuz çalışıyor
- asıl veri `yukle().then(veri => { gorevler = veri; render(); })` içinde atanıyor

- veri gelene kadar `liste.textContent = "yükleniyor..."` gösterdim
- `render()` içindeki `kaydet()` çağrısının veri gelmeden tetiklenmediğinden emin oldum, yoksa boş `gorevler` localStorage'a yazılıyordu.
