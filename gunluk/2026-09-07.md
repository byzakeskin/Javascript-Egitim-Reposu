1. Madde: Hayır her durumda yeterli değilmiş. kaydet() sadece render() çağrıldığında çalışıyor. render() çağırmayan bir fonksiyon yazdığımda gorevler değişiyor evet ama localStorage güncellenmediğini gördüm.

function test(metin) {
    gorevler.push({
        id: Date.now(),
        metin: metin || "deneme metini",
        bitti: false
    });
    // render() çağırmıyorum
}

- Gördüğüm şey ocalStoragedaki gorevler stringinin eski hali(yeni görev orada yok). Sayfayı yenilediğimde de bu görev hiç kaydedilmediği için kaybolacaktır.

2. Madde: gorevler anahtarını depoda ilk kez oluşturan satır, kaydet() fonksiyonunun içindeki:
    
    localStorage.setItem(storageKey, JSON.stringify(gorevler));

    satırım. Öncelikle dosyanın en altında bulunan liste.textContent = "yükleniyor" çalışıyor ardından yukle()'yi çağırıyorum. İlk açılışta null dönüyor kayıt olmadığı için. kayit falsy olunca da if bloğuna giremeyeceğinden fetche düşüyoruz. jsonplaceholderdan veri çekip maple return ediyoruz. yukle().then(function(veri) { gorevler = veri; render(); }) çalışıyor. render() çağrılıyor renderın ilk satırı kaydet(); → kaydet() içinde localStorage.setItem(storageKey, JSON.stringify(gorevler)). var işte bu satırım da sayfa ilk açıldığında fetch bittikten sonra çalışıyor ve bu zincirle key kendiliğinden oluşuyor.
